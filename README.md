# Volter
Lightweight menubar app for managing your Apple silicon Mac's GPU power. 

<img width="353" height="164" alt="image" src="https://github.com/user-attachments/assets/d1b12215-0beb-414e-8013-b4a37e43dfee" />

**How it works**: 
- Modified minimal GPU wattage controller using private Apple silicon APIs, from [maderix](https://github.com/maderix/apple-gpu-dvfs)
- Persistent helper that only requires password on first apply
